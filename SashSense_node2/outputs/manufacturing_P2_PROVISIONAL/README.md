# Provisional manufacturing review outputs

The export script writes Gerbers, drill files, BOM/CPL, assembly drawing, IPC-D-356 and STEP here. This folder is a review package, not a fabrication release.

Before ordering, confirm the beeper, mounting pattern, sensor openings, thickness and power harness, then obtain a fabricator DFM review for the 160 × 60 mm outline. See ../../docs/pcb_layout_review.md.
